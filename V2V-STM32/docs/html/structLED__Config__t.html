Detailed Description

Describes one LED: where it is wired, and which way round it is.

ActiveState is what lets the rest of the firmware say "on" and "off" without knowing how the LED is wired. An ACTIVE_HIGH LED lights when its pin is driven high; an ACTIVE_LOW one lights when the pin is driven low (cathode to the pin, anode to VDD). The driver inverts the level for you.
