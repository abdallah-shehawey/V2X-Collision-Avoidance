Detailed Description

Microcontroller Abstraction Layer — drivers written directly against the STM32F446RE registers.

No vendor HAL/LL library is used anywhere in this project: every peripheral driver below writes the peripheral's registers itself, through the register map in LIB. An MCAL driver knows about the MCU but nothing about the board, so it never refers to a specific LED, sensor or vehicle concept.

Each driver follows the same three-file convention:

  • <NAME>_interface.h — the public API, the enums and the config structs
  • <NAME>_config.h — compile-time tuning knobs for this build
  • <NAME>_private.h — register bit positions and internal helpers
