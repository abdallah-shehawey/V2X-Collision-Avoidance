void IMA_voidProcessNeighbor ( const Neighbor * n)

Process one CROSSING-direction DSRC neighbor for IMA. The SafetyEngine only dispatches crossing-direction neighbors here.

Parameters
nPointer to neighbor data

Process one CROSSING-direction DSRC neighbor for IMA. The SafetyEngine only dispatches crossing-direction neighbors here.

Any crossing vehicle raises an alert so the driver knows an IMA case is in play; the priority rule (higher speed = right of way) only sets its severity:

  • host faster or equal → it passes first → WARNING.
  • host slower → it must yield → CRITICAL. The SafetyEngine only dispatches crossing-direction neighbors here.

nPointer to neighbor data
