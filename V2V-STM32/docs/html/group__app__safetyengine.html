Host vehicle state for the current cycle

SafetyEngine_voidUpdate latches these from G_stHostVehicleState once at the top of each 50 ms cycle, and the modules then read them as they walk the neighbor table.

Latching once is what guarantees every module in a given cycle reasons about the same vehicle state, even though the sensors keep updating.

Direction classification thresholds

How far two vehicles' headings may differ and still count as travelling the same way, opposite ways, or across each other [degrees].

Note
These were widened from 30° to 40° deliberately. Each car reports the heading its own magnetometer measured, and two magnetometers rarely agree to better than a few tens of degrees. A tight threshold therefore kept classifying genuinely same-direction pairs as DIR_UNKNOWN, which silently switched every cooperative module off.

#define HEADING_CROSS_THRESHOLD
 Headings within this of 90° apart → DIR_CROSSING.

Shared safe-distance model

The one place the firmware decides how much room is "enough".

Both distance-based modules — local FCW and EEBL — use it, so a change here moves both, and the two can never drift out of agreement.

The gap scales with speed, because stopping distance does:

*   safe_cm     = max(Host_Speed[m/s] * SAFE_DIST_PER_MS, MIN_SAFE_DISTANCE)
*   critical_cm = safe_cm * CRITICAL_RATIO
*
Note
The constants are sized for the prototype, not a real car: a small vehicle whose top speed is around 0.5 m/s, operating in corridors where obstacles sit tens of centimetres away. At that scale the speed term is small and MIN_SAFE_DISTANCE is what actually governs — it is the dominant floor, not a rarely-hit corner case.
#define SAFE_DIST_PER_MS
 Centimetres of safe gap per 1 m/s of speed.
#define MIN_SAFE_DISTANCE
 Floor on the safe gap [cm], whatever the speed.
#define CRITICAL_RATIO
 Fraction of the safe gap below which the risk is critical.

◆ Direction_t

enum Direction_t

How a neighbor is moving relative to us — the first question every cooperative module asks.

It decides which module even applies: EEBL only makes sense for a car ahead in DIR_SAME, Do-Not-Pass only for DIR_OPPOSITE, IMA only for DIR_CROSSING.

Enumerator
DIR_SAME 

Travelling the same way we are — a car ahead or behind in our lane.

DIR_OPPOSITE 

Coming towards us — oncoming traffic.

DIR_CROSSING 

Crossing our path at roughly a right angle — the intersection case.

DIR_UNKNOWN 

The headings do not fit any of the above within the thresholds.

Modules skip the neighbor rather than guess.

◆ SafetyEngine_voidUpdate()

void SafetyEngine_voidUpdate ( void )

Run one full ADAS cycle: every module, over every neighbor, in one pass.

This is the ADAS brain, and it is the only place a hazard decision is made. Each 50 ms cycle it:

  1. latches Host_Speed and Host_Heading, and computes this cycle's SafetyEngine_SafeDist and SafetyEngine_CriticalDist;
  2. walks the DSRC neighbor table once, offering each neighbor to every module that its Direction_t makes relevant;
  3. aggregates the modules' RiskLevel_t results into G_u16SystemFlags.

The single pass matters: the modules share the neighbor table and the latched host state, so walking it once means they all reason about one coherent snapshot of the world rather than five slightly different ones.

Note
Makes no actuator decision whatsoever. It publishes a status word; vTask_Feedback is what turns that into light and sound.
Warning
The caller must hold both mutexes, taken in the order NeighborTable → Data.

Assess collision risk from host speed and a measured distance.

safe_dist_cm = host_speed(m/s) * dist_per_ms (floored at min_dist) distance >= safe_dist -> RISK_SAFE crit*safe <= distance < safe_dist -> RISK_WARNING distance < crit*safe -> RISK_CRITICAL

Parameters
host_speedHost vehicle speed (m/s, from MPU)
distanceMeasured distance to the object (cm, from ultrasonic)
dist_per_mscm of safe gap per 1 m/s of host speed (module-tuned)
min_distMinimum safe-distance floor (cm)
crit_ratioFraction of safe distance below which risk is CRITICAL
Returns
RISK_SAFE, RISK_WARNING, or RISK_CRITICAL
