◆ SYSTIC_vInit()

void SYSTIC_vInit ( void )

Initialize the SysTick timer with configured settings.

This function initializes the SysTick timer with the following:

  • Configures the clock source (AHB or AHB/8)
  • Sets up interrupt settings if enabled
  • Prepares the timer for delay operations
Note
Must be called before using any other SYSTIC functions
Warning
Ensure proper clock configuration before initialization
Example:
SYSTIC_vInit();

Generate a precise millisecond delay using polling method.

◆ SYSTIC_enumGetElapsedTickSingleShot()

ErrorState_t SYSTIC_enumGetElapsedTickSingleShot ( uint32_t * Copy_pu32Tick)

Generate a precise microsecond delay using polling method.

Parameters
[in]Copy_pu32TickPointer to store the elapsed tick count

This function:

  1. Calculates the number of ticks needed based on clock configuration
  2. Handles delays longer than maximum counter value (24-bit) by breaking them into multiple shorter delays
Returns
OK if the tick count was written to Copy_pu32Tick, NULL_POINTER if it was NULL.
  1. Uses polling method to wait for completion
Note
The actual delay might be slightly longer than requested due to:
  • Function call overhead
  • Context switching (if interrupts are enabled)
  • Clock frequency rounding
Warning
For very short delays (<10µs), the actual elapsed tick count may be longer than requested due to function call overhead
Example:

uint32_t elapsed; SYSTIC_enumGetElapsedTickSingleShot(&elapsed);

Copy_u32TickPeriod, in SysTick ticks.
Return values
OKThe callback was registered and the timer started.

Warning
