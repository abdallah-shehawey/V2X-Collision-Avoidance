◆ DSRC_RemoveStale()

void DSRC_RemoveStale ( uint32_t current_time)

Drop every neighbor that has been silent for NEIGHBOR_TIMEOUT.

Without this, a car that drove away — or whose radio died — would linger in the table forever and keep triggering warnings about a vehicle that is no longer there.

Parameters
current_timeThe current tick count, in the same units as Neighbor::last_update.

◆ DSRC_RxCallback()

void DSRC_RxCallback ( uint8_t byte)

Feed one received byte into the frame parser.

Parameters
byteThe next byte that arrived from the ESP32 on UART1.
Warning
Call this from task context only (vTask_ESP_Comm), never from the USART1 ISR. It mutates the parser's non-atomic internal queue, so an ISR calling it while the task is mid-parse is a data race. The ISR's job is only to push the raw byte onto G_xESP_RX_Queue.
