Detailed Description

Configuration structure for a single Ultrasonic sensor instance.

Note
Each sensor MUST be assigned its own unique Timer (TIM_TIMER2..TIM_TIMER8). This allows multiple sensors to operate simultaneously without conflict. TRIG and ECHO can be ANY available GPIO pin — no pin restriction.
Example:

US_Config_t mySensor = { .Timer = TIM_TIMER2, .TrigPort = GPIO_PORTA, .TrigPin = GPIO_PIN0, .EchoPort = GPIO_PORTA, .EchoPin = GPIO_PIN1 };
