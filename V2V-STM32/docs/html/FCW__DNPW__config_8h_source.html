13/*
14 * ====== Cooperative FCW + DNPW Model ======
15 *
16 * FCW and DNPW share the same cooperative inputs, so they live in one pipeline:
17 *
18 * - FrontObject : front ultrasonic sees something ahead
19 * - Oncoming : a neighbor is heading opposite to us (DSRC heading)
20 * - OncomingHeadon : that oncoming neighbor's broadcast fcw_headon_flag
21 *
22 * Decision (the oncoming car's head-on flag is read only when one exists):
23 * FrontObject, no oncoming -> local FCW
24 * FrontObject + oncoming + its headon -> cooperative head-on FCW
25 * FrontObject + oncoming + no its headon -> DNPW (overtaking)
26 *
27 * Severity comes from the shared cycle gaps (SafetyEngine_SafeDist /
28 * CriticalDist) against the front distance.
29 */
