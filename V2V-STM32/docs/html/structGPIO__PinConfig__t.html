Detailed Description

Full configuration of one pin, as passed to GPIO_enumPinInit.

Otype and Speed only matter when Mode is GPIO_OUTPUT or GPIO_ALTFN; AlternateFunction only matters when Mode is GPIO_ALTFN. The unused members are still written, harmlessly.
