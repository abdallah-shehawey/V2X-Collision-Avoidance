Detailed Description

The PLL dividers that set the system clock frequency.

The PLL takes the source clock and puts it through three stages:

*   f_SYSCLK = f_source / PLLM_Div * PLLN_Mult / PLLP_Div
*

PLLM_Div first brings the source down to the PLL's input frequency, which must land between 1 and 2 MHz (2 MHz is recommended); PLLN_Mult then multiplies it up into the VCO, which must stay between 100 and 432 MHz; and PLLP_Div divides the VCO down to the final system clock, which must not exceed 180 MHz on this part.

Warning
Those three ranges are hardware limits, not style advice. A combination that overshoots them produces a PLL that either never locks or locks at a frequency the flash cannot be read at, and the symptom is a board that appears dead at reset.
