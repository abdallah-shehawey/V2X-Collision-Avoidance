Detailed Description

Bit-manipulation macros used by every register access in the MCAL.

Author
Abdallah Abdelmoemen Shehawey

These are the only primitives the drivers use to touch a peripheral register: an MCAL driver never writes a raw hex mask, it names the bit and uses one of the macros below.

Warning
The arguments are not parenthesised internally. Pass a plain variable and a plain bit index — an expression such as READ_BIT(reg, i + 1) will not parse the way you expect, and READ_BIT(...) used inside a larger expression needs its own parentheses because & binds looser than ==.
