◆ BSW_u8GetSidesSeverity()

uint8_t BSW_u8GetSidesSeverity ( void )

Get the receiver-side blind-spot severity PER SIDE, packed so the Raspberry Pi can tell LEFT from RIGHT (BSW_u8GetSeverity only gives the worst of the two and loses the side).

Returns
byte = (left_severity & 0x3) | ((right_severity & 0x3) << 2) bits 1:0 = LEFT severity (0/1/2), bits 3:2 = RIGHT severity (0/1/2)

◆ BSW_voidProcessNeighbor()

void BSW_voidProcessNeighbor ( const Neighbor * n)

Process one DSRC neighbor for BSW (receiver role).

For each side bit the neighbor broadcasts, check our mirrored rear sensor to see whether this car sits in that neighbor's blind spot. The bits are tested independently, so a both-sides flag runs both checks.

Parameters
nPointer to neighbor data
