TIM1 Update IRQ Handler.

Note
On STM32F446xx, TIM1 Update shares its IRQ line with TIM10. The correct handler name is TIM1_UP_TIM10_IRQHandler. Enable with NVIC IRQ: TIM1_UP_TIM10_IRQn
Advanced-control timer: set MOE bit (BDTR register) if using PWM output.
