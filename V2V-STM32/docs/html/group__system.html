ADAS status word (G_u16SystemFlags)

G_u16SystemFlags packs the result of all five ADAS modules into one 16-bit word, two bits per module.

SafetyEngine_Task is its only writer; Feedback_Task and RPi_Comm_Task are its readers.

Each 2-bit field holds SYS_SAFE, SYS_WARNING or SYS_CRITICAL. The layout is:

Bits Module
1:0 FCW — Forward Collision Warning
3:2 EEBL — Emergency Electronic Brake Light
5:4 BSW — Blind Spot Warning (warning level only)
7:6 DNPW — Do Not Pass Warning
9:8 IMA — Intersection Movement Assist
15:10 reserved, always 0

So 0x0000 means everything is safe, 0x0002 is "FCW critical", and 0x0006 is "FCW critical **and** EEBL warning" at the same time.

Read one module's status with SYS_GET, e.g. SYS_GET(G_u16SystemFlags, SYS_FCW_POS).

Detailed Description

Startup, system-wide configuration and the shared vehicle state.

The System layer owns everything that is global to the firmware rather than to one driver: the FreeRTOS task set in main.c, the pin/peripheral map and the tuning constants in System.h, the shared HostVehicleState_t and ADAS status word, and the newlib stubs in syscalls.c.
