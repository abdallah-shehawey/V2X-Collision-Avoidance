Detailed Description

Doxygen module tree for the V2V-STM32 firmware.

This file declares the module (group) hierarchy only. It contains no code — every source file attaches its symbols to one of the groups below with @addtogroup <id> / @{ ... @}, which is what gives the generated manual its "Modules" tree instead of a flat list of files.

The hierarchy mirrors the layered architecture of the firmware: a symbol may only depend on symbols in its own layer or a layer below it.

*   Application  (SafetyEngine, DSRC, FCW/DNPW, EEBL, BSW, IMA)
*        |
*       HAL      (LED, BUZZ, US, MPU9250)
*        |
*      MCAL      (RCC, GPIO, NVIC, SCB, SYSCFG, SYSTICK, EXTI, SPI, TIM, USART, IWDG)
*        |
*       LIB      (ErrTypes, STD_MACROS, STM32F446xx register map)
*        |
*    Hardware    (STM32F446RE, Cortex-M4)
