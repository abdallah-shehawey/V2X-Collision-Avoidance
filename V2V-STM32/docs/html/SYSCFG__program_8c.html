void SYSCFG_vSetEXTIConfig ( SYSCFG_EXTI_t Copy_u8EXTI,
SYSCFG_Port_t Copy_u8Port )

Choose which GPIO port drives a given EXTI line.

EXTI line N is shared by pin N of every port — PA3, PB3 and PC3 all map to EXTI3 — and only one of them can own the line. This is where that choice is made.

Parameters
Copy_u8EXTIEXTI line to route, 0..15.
Copy_u8PortThe port whose pin should drive it.
Note
Without this call an EXTI line defaults to port A, so an interrupt configured on, say, PB4 is simply never delivered. It has to run before EXTI_vLineInit.
