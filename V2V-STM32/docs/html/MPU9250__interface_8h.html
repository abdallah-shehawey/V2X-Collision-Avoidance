ErrorState_t MPU9250_enumCalibrateMag ( void )

Boot-time hard-iron calibration. Rotate the vehicle ~360° during the window (length = MPU9250_MAGCAL_DURATION_MS); computes & freezes the magnetometer X/Y bias offsets.

Returns
OK if enough rotation was seen (offsets applied), NOK if the field span was too small (offsets left unchanged).
