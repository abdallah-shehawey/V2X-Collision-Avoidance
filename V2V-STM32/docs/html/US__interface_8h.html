ErrorState_t US_u16ReadDistance_cm ( const US_Config_t * pxSensor,
uint16_t * pu16Dist_cm )

Trigger sensor and measure distance (cm). The calling task SLEEPS on a semaphore while the echo is in flight (CPU free), then the IC ISR wakes it with the result. Returns TIMEOUT_STATE if no echo within the window.

Note
MUST be called from a task context (uses a FreeRTOS semaphore). Not reentrant: one measurement at a time (sequential by design).
