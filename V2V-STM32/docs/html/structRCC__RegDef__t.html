Detailed Description

RCC (reset and clock control) register layout.

This is the peripheral the MCAL RCC driver uses to bring the clock tree up to 180 MHz and to gate the clock of every other peripheral on. A peripheral whose clock is not enabled here reads back as all zeroes and silently ignores writes, which is the single most common bring-up bug in a bare-metal driver.
