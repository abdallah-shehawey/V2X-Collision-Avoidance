Detailed Description

Hardware Abstraction Layer — board-level devices built on top of MCAL.

A HAL driver knows what is physically wired to the board (an LED on a given pin, an HC-SR04 on a trigger/echo pair, an MPU9250 on SPI1) but knows nothing about collision avoidance. It exposes the device in the device's own terms (LED_enumOn, US_f32GetDistance, MPU9250_voidGetHeading) and leaves all policy to the Application layer.
