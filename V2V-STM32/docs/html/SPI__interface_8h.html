◆ SPI_CPHA_t

enum SPI_CPHA_t

Clock phase: which SCK edge the data is sampled on.

Together with SPI_CPOL_t this picks the SPI mode (0..3). Get it wrong and the peripheral samples the line while the slave is still changing it, so every byte comes back shifted or garbled.

Enumerator
SPI_CPHA_1EDGE 

Sample on the first clock edge.

With SPI_CPOL_LOW this is SPI mode 0 — what the MPU9250 wants.

SPI_CPHA_2EDGE 

Sample on the second clock edge.

◆ SPI_BAUDRATEPRESCALER_t

enum SPI_BAUDRATEPRESCALER_t

Divider from the APB clock down to SCK.

Note
The MPU9250 tolerates 20 MHz for register access but only 1 MHz for reading its sensor registers, so the prescaler must be chosen against the slower of the two limits.
