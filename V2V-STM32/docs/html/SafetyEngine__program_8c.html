RiskLevel_t SafetyEngine_AssessDistanceRisk ( float host_speed,
float distance,
float dist_per_ms,
float min_dist,
float crit_ratio )

Assess collision risk from host speed and a measured distance.

safe_dist_cm = host_speed(m/s) * dist_per_ms (floored at min_dist) distance >= safe_dist -> RISK_SAFE crit*safe <= distance < safe_dist -> RISK_WARNING distance < crit*safe -> RISK_CRITICAL

Parameters
host_speedHost vehicle speed (m/s, from MPU)
distanceMeasured distance to the object (cm, from ultrasonic)
dist_per_mscm of safe gap per 1 m/s of host speed (module-tuned)
min_distMinimum safe-distance floor (cm)
crit_ratioFraction of safe distance below which risk is CRITICAL
Returns
RISK_SAFE, RISK_WARNING, or RISK_CRITICAL
