float CalcHeadingDiff ( float h1,

static

Absolute difference between two headings, normalised to 0..180 degrees.

Parameters
h1First heading [degrees], 0..360.
h2Second heading [degrees], 0..360.
Returns
The angle between them [degrees], 0..180.
Note
Headings are circular, so the naive |h1 - h2| is wrong: 350° and 10° are 20° apart, not 340°. Normalising here is what stops two cars that are plainly travelling the same way being classified as DIR_OPPOSITE whenever they happen to be pointing near north.
