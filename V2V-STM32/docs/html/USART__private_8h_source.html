43/* Busy-wait safety net for TXE/RXNE. This is a stuck-hardware bound ONLY and
44 * must NEVER expire during a legitimate byte transfer. The previous value
45 * (20000) was far too small: under load it expired mid-stream while TXE was
46 * still 0, so USART_enumTransmit dropped the byte silently and the DSRC frame
47 * arrived truncated (the ESP saw 14-20 bytes/packet instead of 23, failing
48 * every END/checksum). One byte @115200 = ~87us; @57600 = ~174us. Sized to
49 * cover many milliseconds of wait even under -O3 so a real transfer always
50 * completes, while still escaping a genuinely-dead peripheral. */
