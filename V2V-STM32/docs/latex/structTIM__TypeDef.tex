\doxysubsection{Detailed Description}
Timer register layout, in the superset form used by TIM1/\+\+TIM8. 

The general-\/purpose and basic timers implement only part of this layout; the members they lack read as zero. The firmware uses the timers as the time base for the ultrasonic echo measurement and for PWM.
