\doxysubsection{Detailed Description}
The ADAS brain:\+ the DSRC transport, the shared risk model, and the five cooperative collision-\/avoidance modules. 

Every module in this layer is driven from \doxylink{group__app__safetyengine_ga7b6c12632534a82b4357a73306667157}{Safety\+Engine\+\_\+void\+Update} once per 50 ms cycle, consumes the same DSRC neighbor table, and returns the same graded result:\+ 0 = safe, 1 = warning, 2 = critical. No module in this layer touches a GPIO or a UART directly — it computes a flag, and {\ttfamily Feedback\+\_\+\+Task} renders it. \input{group__app__safetyengine}
