Process one DSRC neighbor for BSW (receiver role). 

A neighbor broadcasts the front side(s) on which it sees a car. That car sits behind the neighbor on the mirrored side, so each side bit maps to our opposite rear sensor:\+ sender LEFT (its front-\/left) -\/\texorpdfstring{$>$}{>} check our REAR-\/\+RIGHT sender RIGHT (its front-\/right) -\/\texorpdfstring{$>$}{>} check our REAR-\/\+LEFT The bits are tested independently, so BSW\+\_\+\+FLAG\+\_\+\+BOTH runs both checks.
