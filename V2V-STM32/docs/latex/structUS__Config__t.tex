\doxysubsection{Detailed Description}
Configuration structure for a single Ultrasonic sensor instance. 

\begin{DoxyNote}{Note}
Each sensor MUST be assigned its own unique Timer (TIM\+\_\+\+TIMER2..TIM\+\_\+\+TIMER8). This allows multiple sensors to operate simultaneously without conflict. TRIG and ECHO can be ANY available GPIO pin — no pin restriction.
\end{DoxyNote}
