\doxysubsection{Detailed Description}
Doxygen module tree for the V2\+V-\/\+STM32 firmware. 

This file declares the module (group) hierarchy only. It contains no code — every source file attaches its symbols to one of the groups below with {\ttfamily @addtogroup \texorpdfstring{$<$}{<}id\texorpdfstring{$>$}{>}} /\+ {\ttfamily @\{} ... {\ttfamily @\}}, which is what gives the generated manual its "{}\+Modules"{} tree instead of a flat list of files.

The hierarchy mirrors the layered architecture of the firmware:\+ a symbol may only depend on symbols in its own layer or a layer below it.
