\doxysubsection{Detailed Description}
Hardware Abstraction Layer — board-\/level devices built on top of MCAL. 

A HAL driver knows what is physically wired to the board (an LED on a given pin, an HC-\/\+SR04 on a trigger/\+echo pair, an MPU9250 on SPI1) but knows nothing about collision avoidance. It exposes the device in the device\textquotesingle{}s own terms ({\ttfamily LED\+\_\+enum\+On}, {\ttfamily US\+\_\+f32\+Get\+Distance}, {\ttfamily MPU9250\+\_\+void\+Get\+Heading}) and leaves all policy to the Application layer. \input{group__hal__led}
