\doxysubsection{Detailed Description}
The PLL dividers that set the system clock frequency. 

The PLL takes the source clock and puts it through three stages:\+

\begin{DoxyVerb}*   f_SYSCLK = f_source / PLLM_Div * PLLN_Mult / PLLP_Div
* \end{DoxyVerb}


{\ttfamily \doxylink{structRCC__PLLConfig__t_a4ced7907a8b3208d084ef5835e62466f}{PLLM\+\_\+\+Div}} first brings the source down to the PLL\textquotesingle{}s input frequency, which {\bfseries{must land between 1 and 2 MHz}} (2 MHz is recommended); {\ttfamily \doxylink{structRCC__PLLConfig__t_aac81bf0a8a6b4773f37ae33dd426bbf2}{PLLN\+\_\+\+Mult}} then multiplies it up into the VCO, which must stay between 100 and 432 MHz; and {\ttfamily \doxylink{structRCC__PLLConfig__t_a1c948324f41858be945f948a1a5751c9}{PLLP\+\_\+\+Div}} divides the VCO down to the final system clock, which must not exceed 180 MHz on this part.

\begin{DoxyWarning}{Warning}
Those three ranges are hardware limits, not style advice. A combination that overshoots them produces a PLL that either never locks or locks at a frequency the flash cannot be read at, and the symptom is a board that appears dead at reset. 
\end{DoxyWarning}
