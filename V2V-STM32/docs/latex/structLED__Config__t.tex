\doxysubsection{Detailed Description}
Describes one LED:\+ where it is wired, and which way round it is. 

{\ttfamily \doxylink{structLED__Config__t_a569c6b77190bc29ef3c64bea8fb8b1c9}{Active\+State}} is what lets the rest of the firmware say "{}on"{} and "{}off"{} without knowing how the LED is wired. An \doxylink{LED__interface_8h_a59d24514299cc1e14e907d084535e845afe240f1952811db0c18b4355fb28190f}{ACTIVE\+\_\+\+HIGH} LED lights when its pin is driven high; an \doxylink{LED__interface_8h_a59d24514299cc1e14e907d084535e845a43ad983a1a6a3c04a137ec0471cdfe85}{ACTIVE\+\_\+\+LOW} one lights when the pin is driven {\itshape low} (cathode to the pin, anode to VDD). The driver inverts the level for you.
