\doxysubsection{Detailed Description}
\doxylink{structNeighbor}{Neighbor} table, frame parser and transmitter for the V2V link. 

\begin{DoxyAuthor}{Author}
Abdallah Shehawey 
\end{DoxyAuthor}
Three pieces live here:\+


\begin{DoxyEnumerate}
\item a {\bfseries{byte-\/at-\/a-\/time frame parser}} (\doxylink{group__app__dsrc_ga8f2c7037352677729c777df880fefd1b}{DSRC\+\_\+\+Rx\+Callback}), written as an explicit state machine so a garbled or half-\/received frame can never leave the parser stuck — it simply falls back to \doxylink{DSRC_8c_a99f78dec5b5884642b44f101ef1d2460ad672f41b357cfe8db0e7b262a428fd66}{WAIT\+\_\+\+START};
\item a small {\bfseries{queue}} of successfully parsed frames, which decouples parsing from the table update;
\item the {\bfseries{neighbor table}} itself, one row per vehicle heard from recently.
\end{DoxyEnumerate}

See \doxysectlink{DSRC_8h_dsrc_frame}{Frame layout}{1} in \doxylink{DSRC_8h}{DSRC.\+h} for the frame layout.
