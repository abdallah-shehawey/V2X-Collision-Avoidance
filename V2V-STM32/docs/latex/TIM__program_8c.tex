Timer input clock \+[Hz]\+, used to turn prescaler values into real time. 

\begin{DoxyNote}{Note}
Only a fallback — the build normally defines this. If it is ever wrong, every computed period and every measured echo is scaled by the same factor, so distances come out proportionally wrong rather than random. 
\end{DoxyNote}
