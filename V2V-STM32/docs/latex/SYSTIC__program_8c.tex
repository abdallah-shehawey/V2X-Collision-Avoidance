Sys\+Tick Timer Driver Implementation

This file implements the Sys\+Tick timer functionality for STM32\+F446\+RE microcontroller. Sys\+Tick is a 24-\/bit down counter that can be used for generating precise delays and periodic interrupts. The driver supports both polling and interrupt-\/based operation modes.
