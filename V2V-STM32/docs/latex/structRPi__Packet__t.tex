\doxysubsection{Detailed Description}
Legacy binary telemetry packet — {\bfseries{kept for reference only}}. 

\begin{DoxyRefDesc}{Deprecated}
\item[\doxymbox{\hyperlink{deprecated__deprecated000001}{Deprecated}}]Nothing sends this any more. {\ttfamily RPi\+\_\+\+Comm\+\_\+\+Task} streams an ASCII CSV line instead, because this packed layout contains {\ttfamily 0x00} bytes and those were being lost on the UART link, which silently truncated whole runs.\end{DoxyRefDesc}
