\item {\bfseries{Engine temperature + weather}} — stat tiles on the left
\item {\bfseries{6 ultrasonic sensors}} — top-\/down car view; each sensor shows live distance and lights up green → yellow → red as an obstacle gets closer

\item {\bfseries{Event log + overall risk level}} — auto-\/generated from state changes
