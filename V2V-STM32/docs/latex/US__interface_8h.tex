Trigger sensor and measure distance (cm). The calling task SLEEPS on a semaphore while the echo is in flight (CPU free), then the IC ISR wakes it with the result. Returns TIMEOUT\+\_\+\+STATE if no echo within the window. 

\begin{DoxyNote}{Note}
MUST be called from a task context (uses a Free\+RTOS semaphore). Not reentrant:\+ one measurement at a time (sequential by design). 
\end{DoxyNote}
