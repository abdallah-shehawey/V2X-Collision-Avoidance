\doxysubsubsection*{ADAS status word (G\+\_\+u16\+System\+Flags)}
\doxylink{group__system_ga9e78367aa5b758af972838362c2b0eab}{G\+\_\+u16\+System\+Flags} packs the result of all five ADAS modules into one 16-\/bit word, two bits per module.

{\ttfamily Safety\+Engine\+\_\+\+Task} is its only writer; {\ttfamily Feedback\+\_\+\+Task} and {\ttfamily RPi\+\_\+\+Comm\+\_\+\+Task} are its readers.

Each 2-\/bit field holds \doxylink{group__system_ga167de614bc64dfddcd8a7677b6fecda0}{SYS\+\_\+\+SAFE}, \doxylink{group__system_gad8f58f6c26f6d5da69980ba995e38c78}{SYS\+\_\+\+WARNING} or \doxylink{group__system_ga717d9a716e77febf5c57b5c7231802c8}{SYS\+\_\+\+CRITICAL}. The layout is:\+


\begin{DoxyTable}{2}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Bits  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Module  \\
1:\+0  &FCW — Forward Collision Warning  \\
3:\+2  &EEBL — Emergency Electronic Brake Light  \\
5:\+4  &BSW — Blind Spot Warning (warning level only)  \\
7:\+6  &DNPW — Do Not Pass Warning  \\
9:\+8  &IMA — Intersection Movement Assist  \\
15:\+10  &reserved, always 0  \\
\end{DoxyTable}


So {\ttfamily 0x0000} means everything is safe, {\ttfamily 0x0002} is "{}\+FCW critical"{}, and {\ttfamily 0x0006} is "{}\+FCW critical \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}and\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} EEBL warning"{} at the same time.

\doxysubsection{Detailed Description}
Startup, system-\/wide configuration and the shared vehicle state. 

The System layer owns everything that is global to the firmware rather than to one driver:\+ the Free\+RTOS task set in {\ttfamily \doxylink{main_8c}{main.\+c}}, the pin/\+peripheral map and the tuning constants in {\ttfamily \doxylink{System_8h}{System.\+h}}, the shared \doxylink{structHostVehicleState__t}{Host\+Vehicle\+State\+\_\+t} and ADAS status word, and the newlib stubs in {\ttfamily \doxylink{syscalls_8c}{syscalls.\+c}}.
