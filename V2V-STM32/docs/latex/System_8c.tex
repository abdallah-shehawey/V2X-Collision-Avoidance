USART1 receive ISR callback:\+ push one byte onto \doxylink{main_8c_a2c251aeac2c84008a206658c306be262}{G\+\_\+x\+ESP\+\_\+\+RX\+\_\+\+Queue}. 

Called from interrupt context for every byte the ESP32 sends. It does the minimum possible — read the byte, enqueue it — and leaves all DSRC framing and parsing to \doxylink{main_8c_a8e83024643794f31ab8139cbdb1de5dd}{v\+Task\+\_\+\+ESP\+\_\+\+Comm}, which can afford to block on a mutex.

The byte is read straight out of the USART data register rather than through the driver\textquotesingle{}s blocking receive, because polling the busy flag here would deadlock against a transmission already in progress.

\begin{DoxyWarning}{Warning}
Runs in interrupt context, so it may only use the {\ttfamily ...From\+ISR} Free\+RTOS API. That in turn requires USART1\textquotesingle{}s NVIC priority to be numerically {\bfseries{at or above}} {\ttfamily config\+MAX\+\_\+\+SYSCALL\+\_\+\+INTERRUPT\+\_\+\+PRIORITY} (5) — see the warning on \doxysectlink{System_8h_sys_tasks}{Task set}{1}. 
\end{DoxyWarning}

Free\+RTOS stack-\/overflow hook:\+ a task ran off the end of its stack. 


\begin{DoxyParams}{Parameters}
{\em x\+Task} & Handle of the offending task. \\
\hline
{\em pc\+Task\+Name} & Its name, which is the useful part when this fires under a debugger.\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
Halts with interrupts disabled rather than trying to recover. There is no recovering:\+ the task\textquotesingle{}s stack has already overwritten whatever sat below it, so memory is corrupt and continuing would just hide the cause. Stopping here also stops the watchdog being kicked, so the MCU resets — which is the safe outcome in a vehicle. 
\end{DoxyNote}
