\doxysubsection{Detailed Description}
SYSCFG (system configuration controller) register layout. 

Its only job in this firmware is EXTICR:\+ choosing {\itshape which port\textquotesingle{}s} pin N drives EXTI line N. Without it, every EXTI line would default to port A, and the six ultrasonic echo interrupts would never fire.
