Choose which GPIO port drives a given EXTI line. 

EXTI line {\itshape N} is shared by pin {\itshape N} of every port — PA3, PB3 and PC3 all map to EXTI3 — and only one of them can own the line. This is where that choice is made.


\begin{DoxyParams}{Parameters}

\hline
{\em Copy\+\_\+u8\+Port} & The port whose pin should drive it.\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
