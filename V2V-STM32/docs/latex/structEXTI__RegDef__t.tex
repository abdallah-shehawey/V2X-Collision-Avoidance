\doxysubsection{Detailed Description}
EXTI (external interrupt/\+event controller) register layout. 

Every register holds one bit per EXTI line (0..22). The six HC-\/\+SR04 echo pins are configured here for both-\/edge triggering:\+ the rising edge starts the echo timing, the falling edge ends it.
