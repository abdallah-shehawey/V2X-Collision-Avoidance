\doxysubsection{Detailed Description}
Project-\/wide return codes and boolean-\/style constants. 

\begin{DoxyAuthor}{Author}
Abdallah Abdelmoemen Shehawey 
\end{DoxyAuthor}
Every driver in the firmware that can fail returns an \doxylink{group__lib_ga74f58890b599c641e4382ff49c4a3e81}{Error\+State\+\_\+t} rather than a bare integer, so a caller can always tell {\itshape why} a call failed (bad pointer, peripheral busy, timed out) instead of only {\itshape that} it failed. Drivers that cannot fail return {\ttfamily void}.
