\doxysubsection{Detailed Description}
Microcontroller Abstraction Layer — drivers written directly against the STM32\+F446\+RE registers. 

No vendor HAL/\+\+LL library is used anywhere in this project:\+ every peripheral driver below writes the peripheral\textquotesingle{}s registers itself, through the register map in \doxylink{group__lib}{LIB}. An MCAL driver knows about the MCU but nothing about the board, so it never refers to a specific LED, sensor or vehicle concept.

Each driver follows the same three-\/file convention:\+
\begin{DoxyItemize}
\item {\ttfamily \texorpdfstring{$<$}{<}NAME\texorpdfstring{$>$}{>}\+\_\+interface.\+h} — the public API, the enums and the config structs
\item {\ttfamily \texorpdfstring{$<$}{<}NAME\texorpdfstring{$>$}{>}\+\_\+config.\+h} — compile-\/time tuning knobs for this build
\item {\ttfamily \texorpdfstring{$<$}{<}NAME\texorpdfstring{$>$}{>}\+\_\+private.\+h} — register bit positions and internal helpers
