Process one CROSSING-\/direction DSRC neighbor for IMA. The Safety\+Engine only dispatches crossing-\/direction neighbors here.

Any crossing vehicle raises an alert so the driver knows an IMA case is in play; the priority rule (higher speed = right of way) only sets its severity:\+
\begin{DoxyItemize}

\item host slower → it must yield → CRITICAL. The Safety\+Engine only dispatches crossing-\/direction neighbors here.
