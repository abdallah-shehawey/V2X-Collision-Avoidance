Reads ALL 6 ultrasonics + MPU9250 every cycle, then a small gap. 

The US driver is interrupt-\/driven:\+ the task SLEEPS during each echo flight (CPU free), so all 6 can be read back-\/to-\/back without hogging the CPU. Reads are sequential → no acoustic cross-\/talk.

Adaptive refresh:\+ full scan ≈ sum of echo times (near objects → \texorpdfstring{$\sim$}{\string~}15-\/45ms, all out of range → \texorpdfstring{$\sim$}{\string~}150ms with the 4m cap). Much faster than the old 300ms.

All values are computed into locals first, then published in ONE short mutex section. Speed stored as cm/\+s so ADAS TTC (distance\+\_\+cm /\+ speed\+\_\+cm\+\_\+s) = seconds.

void v\+Task\+\_\+\+Watchdog (\begin{DoxyParamCaption}\item[{void \texorpdfstring{$\ast$}{*}}]{pv\+Parameters}{}\end{DoxyParamCaption})}



Liveness monitor + watchdog kicker (lowest priority). 

Every WDG\+\_\+\+CHECK\+\_\+\+PERIOD\+\_\+\+MS it snapshots every task\textquotesingle{}s heartbeat. It refreshes the IWDG ONLY if ALL of them advanced since the last check. If any task stalled — hard fault /\+ stack-\/overflow halt /\+ infinite loop /\+ ISR storm /\+ starvation — its heartbeat freezes, the refresh is skipped, and the IWDG hardware-\/resets the MCU after WDG\+\_\+\+TIMEOUT\+\_\+\+MS. Transient stalls shorter than the IWDG timeout are tolerated (the next healthy check kicks the dog again).

Runs at the LOWEST user priority so that CPU starvation by ANY other task also stops the kicks. The task is self-\/covering:\+ if IT hangs, no kicks → reset.
