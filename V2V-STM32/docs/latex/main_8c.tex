\doxysubsection{Detailed Description}
Entry point, the six Free\+RTOS tasks, and the watchdog liveness net. 

\begin{DoxyAuthor}{Author}
Abdallah Saleh 
\end{DoxyAuthor}
{\ttfamily \doxylink{main_8c_a840291bc02cba5474a4cb46a9b9566fe}{main()}} brings the board up (\doxylink{group__system_gae436954cd2bde6634ab271317d2494a7}{System\+\_\+setup}), then hands control to the scheduler (\doxylink{group__system_ga9f28a641641de8e783815ab1fa92549f}{RTOS\+\_\+setup}). Everything after that happens in one of six tasks; see \doxysectlink{System_8h_sys_tasks}{Task set}{1} for their priorities and periods.

The tasks are deliberately split {\bfseries{brain /\+ muscle}}:\+ \doxylink{main_8c_a1fa00ec0e4cf92155fcaa535be5ab3a1}{v\+Task\+\_\+\+Safety\+Engine} decides, and nothing else does. It writes its verdict into \doxylink{group__system_ga9e78367aa5b758af972838362c2b0eab}{G\+\_\+u16\+System\+Flags}, and \doxylink{main_8c_a96452f43e9871212929e6e6a969bec13}{v\+Task\+\_\+\+Feedback} simply renders that word onto the LEDs and buzzer without re-\/deriving anything.\hypertarget{main_8c_main_wdg}{}\doxysubsection{\texorpdfstring{The watchdog net}{The watchdog net}}\label{main_8c_main_wdg}
Every monitored task bumps its own slot in \doxylink{main_8c_abf287e574f76db7ad0c43062a788d58c}{G\+\_\+au32\+Heartbeat} on each loop. \doxylink{main_8c_ae1bcb9c7fb7ee6cb777db33125685421}{v\+Task\+\_\+\+Watchdog} refreshes the hardware IWDG {\bfseries{only while every slot is still advancing}}. If any single task stalls — hard fault, stack overflow, infinite loop, ISR storm, or simple starvation — its slot freezes, the refresh stops, and the IWDG hardware-\/resets the MCU after \doxylink{main_8c_a83bb26015dd24416bf6b59ad49e55c9b}{WDG\+\_\+\+TIMEOUT\+\_\+\+MS}.

This is why the check is per-\/task rather than a single "{}\+I\textquotesingle{}m alive"{} flag:\+ a watchdog kicked from one healthy task would happily keep the MCU running with a dead ADAS task.

\+\#define SENSORS\+\_\+\+CYCLE\+\_\+\+GAP\+\_\+\+MS}



Rest inserted after each full 6-\/sensor scan \+[ms]\+. 

Two jobs:\+ it guarantees the lower-\/priority tasks some CPU, and it sets the minimum spacing between scans. The scan itself has no fixed length — it is adaptive, because each reading takes as long as its echo takes to come back, so near objects produce a naturally faster refresh than distant ones.

The byte is read straight out of the USART data register rather than through the driver\textquotesingle{}s blocking receive, because polling the busy flag here would deadlock against a transmission already in progress.

\begin{DoxyWarning}{Warning}
Runs in interrupt context, so it may only use the {\ttfamily ...From\+ISR} Free\+RTOS API. That in turn requires USART1\textquotesingle{}s NVIC priority to be numerically {\bfseries{at or above}} {\ttfamily config\+MAX\+\_\+\+SYSCALL\+\_\+\+INTERRUPT\+\_\+\+PRIORITY} (5) — see the warning on \doxysectlink{System_8h_sys_tasks}{Task set}{1}. 
\end{DoxyWarning}
