\begin{Indent}\textbf{ ADAS status word (G\+\_\+u16\+System\+Flags)}\par
{\em \doxylink{group__system_ga9e78367aa5b758af972838362c2b0eab}{G\+\_\+u16\+System\+Flags} packs the result of all five ADAS modules into one 16-\/bit word, two bits per module.

{\ttfamily Safety\+Engine\+\_\+\+Task} is its only writer; {\ttfamily Feedback\+\_\+\+Task} and {\ttfamily RPi\+\_\+\+Comm\+\_\+\+Task} are its readers.

\doxysubsection{Detailed Description}
System-\/wide contract:\+ the board wiring map, the shared vehicle state, the packed ADAS status word, and the telemetry format. 

\begin{DoxyAuthor}{Author}
Abdallah Saleh 
\end{DoxyAuthor}
Everything in this header is shared between tasks, so it is also where the concurrency rules live. Three globals cross task boundaries:\+


\begin{DoxyItemize}
\item \doxylink{group__system_gac3116f56a230ebdd81cadd527921464c}{G\+\_\+st\+Host\+Vehicle\+State} — written by {\ttfamily Sensors\+\_\+\+Task}, read by everyone else.
\item \doxylink{group__system_ga9e78367aa5b758af972838362c2b0eab}{G\+\_\+u16\+System\+Flags} — written by {\ttfamily Safety\+Engine\+\_\+\+Task}, read by {\ttfamily Feedback\+\_\+\+Task} and {\ttfamily RPi\+\_\+\+Comm\+\_\+\+Task}.
\item \doxylink{group__system_ga10d54e2c66effa6800db6f78aaec485c}{Host\+\_\+\+Dist\+To\+Intersection} — written by whatever supplies intersection geometry, read by IMA.
\end{DoxyItemize}

Both mutexes are always taken in the order {\bfseries{Neighbor\+Table → Data}}, and never nested from more than one place, which is what makes the task set deadlock-\/free by construction.\hypertarget{System_8h_sys_wiring}{}\doxysubsection{\texorpdfstring{Board wiring map}{Board wiring map}}\label{System_8h_sys_wiring}
{\bfseries{Ultrasonic sensors — 3 front, 3 rear.}} Echo pins are EXTI inputs; trigger pins are plain outputs. The echo pins were chosen to leave PA0..PA3 free for the UARTs.
