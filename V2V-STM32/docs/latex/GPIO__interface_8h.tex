\doxysubsection{Detailed Description}
Public API of the GPIO driver:\+ pin/\+port configuration and I/\+O. 

\begin{DoxyAuthor}{Author}
Abdallah Abdelmoemen Shehawey 
\end{DoxyAuthor}
The driver works at three granularities, all backed by the same registers:\+


\begin{DoxyItemize}
\item {\bfseries{single pin}} — \doxylink{group__mcal__gpio_ga2a5e7c89bc6bb7103d96334a8481ea9b}{GPIO\+\_\+enum\+Pin\+Init}, \doxylink{group__mcal__gpio_gab8efebd278bcf731012c238a3f69fb5c}{GPIO\+\_\+enum\+Write\+Pin\+Val}, \doxylink{group__mcal__gpio_ga3f0a533051c125627062a50e8a38fded}{GPIO\+\_\+enum\+Read\+Pin\+Val}, \doxylink{group__mcal__gpio_gaacd1fe5ce0d15fd5040c41745409ca20}{GPIO\+\_\+enum\+Tog\+Pin\+Val}. This is what the LED, buzzer and ultrasonic drivers use.
\item {\bfseries{a slice of a port}} — a nibble (4 pins), a byte (8 pins), a half-\/port or a whole port, configured in one call so a parallel bus does not need sixteen separate init calls.
\item {\bfseries{raw port access}} — \doxylink{group__mcal__gpio_ga518fc2c707c44cdc8a356ba08d27f4a6}{GPIO\+\_\+enum\+Read\+Port\+Val} and friends.
\end{DoxyItemize}

Every entry point validates its arguments and reports the outcome through \doxylink{group__lib_ga74f58890b599c641e4382ff49c4a3e81}{Error\+State\+\_\+t}; none of them can fault on a bad port or pin index.

\begin{DoxyNote}{Note}
The port\textquotesingle{}s clock must already be enabled in RCC ({\ttfamily RCC\+\_\+enum\+AHB1\+Enable\+CLK}) before any function here has an effect:\+ a GPIO port with its clock gated off ignores writes and reads back as zero. 
\end{DoxyNote}
