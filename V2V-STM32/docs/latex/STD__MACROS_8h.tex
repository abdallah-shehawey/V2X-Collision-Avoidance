\doxysubsection{Detailed Description}
Bit-\/manipulation macros used by every register access in the MCAL. 

\begin{DoxyAuthor}{Author}
Abdallah Abdelmoemen Shehawey 
\end{DoxyAuthor}
These are the only primitives the drivers use to touch a peripheral register:\+ an MCAL driver never writes a raw hex mask, it names the bit and uses one of the macros below.

\begin{DoxyWarning}{Warning}
The arguments are not parenthesised internally. Pass a plain variable and a plain bit index — an expression such as {\ttfamily \doxylink{group__lib_gaaef49ab0462bf902b59383f592140b05}{READ\+\_\+\+BIT}(reg, i + 1)} will not parse the way you expect, and {\ttfamily \doxylink{group__lib_gaaef49ab0462bf902b59383f592140b05}{READ\+\_\+\+BIT(...)}} used inside a larger expression needs its own parentheses because {\ttfamily \&} binds looser than {\ttfamily ==}. 
\end{DoxyWarning}
