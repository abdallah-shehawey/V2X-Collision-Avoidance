\doxysubsection{Detailed Description}
Line settings for a USART used in {\bfseries{polled}} mode. 

The classic "{}baud rate, word length, parity, stop bits"{} set. Use this when the peripheral is driven by blocking send/\+receive calls. For an interrupt-\/driven port — which is what USART1 needs, since the ESP32 sends unprompted — use \doxylink{structUSART__Handle__t}{USART\+\_\+\+Handle\+\_\+t} instead, which adds the interrupt enables and the callback.
